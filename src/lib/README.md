# lib

Low-level, framework-agnostic helpers. Modules are added when the corresponding
infrastructure lands.

| Module    | Responsibility                                | Status  |
| --------- | --------------------------------------------- | ------- |
| `utils/`  | Shared utilities (currently `errors.ts`)      | Active  |
| `supabase/` | Supabase client (db, auth, storage)         | Planned |
| `auth/`   | Session/identity helpers                      | Planned |
| `security/` | Secret handling, safe string helpers        | Planned |
